## 六、反复上电（**本次最关键的一项**）

因为 `sd_card_clk` 域内仍有 −3.736ns 真违例，**SD 卡初始化是概率性失败的高发点**。
布局一变，这条路径的走线也跟着变，所以必须用重复上电来暴露偶发问题。

| 次数 | 出图 | 出图耗时 | 图片正确 | 异常现象 |
|---|---|---|---|---|
| 第 1 次 | | | | |
| 第 2 次 | | | | |
| 第 3 次 | | | | |
| 第 4 次 | | | | |
| 第 5 次 | | | | |

**判定**：
- 5 次全部正常 → **E1 通过**，可以往 R1b / R2 走
- 出现某次读不到图 / 花屏 / 需要二次上电 → **记为偶发失败**，很可能就是那条 −3.736ns 违例导致的，
  这时应考虑两条路：① 降 `sd_card_clk` 到 70MHz（立刻转正）② 强攻 R1b
