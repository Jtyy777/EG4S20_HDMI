# SD 卡演示素材说明

本目录的 4 个 BMP 是卡内演示素材（垃圾分类公益广告），直接拷贝到 SD 卡**根目录**即可。
卡上不要留其它 `.BMP`：`bmp_read` 只取根目录中按目录项顺序的前 4 个（`SCAN_TARGET_COUNT = 4`）。

## 规格

| 文件 | 卡内分辨率 | 比例 | 大小 | 读卡 @100MHz SPI | 屏内显示 | 黑边 |
|---|---|---|---|---|---|---|
| IMG0.BMP | **640×480** | 4:3 | 0.88 MB | 0.30 s | 640×480，1:1 无缩放 | 无 |
| IMG1.BMP | **800×600** | 4:3 | 1.37 MB | 0.46 s | 640×480 | 无 |
| IMG2.BMP | **1024×768** | 4:3 | 2.25 MB | 0.76 s | 640×480 | 无 |
| IMG3.BMP | **1280×720** | 16:9 | 2.64 MB | 0.89 s | 640×360 | 上下各 60 行 |

合计 7.14 MB。三张 4:3 铺满、一张 16:9 补黑边，用于演示"等比缩放 + 宽高比不符自动补黑边"。

四档分辨率是刻意保留的：作品介绍里表 5 与图 3-10 讲的就是多分辨率适配，全做成 640×480 就没有素材支撑了。

## 内容与制作流程

底图由图像模型生成，中文标题由程序叠加（模型画中文会糊，字必须是锐的）。

排版四张完全一致，轮播时版式不跳：

- 左侧 56% 宽白色渐变蒙版，压住任何底色都能看清标题；
- 两行主标题 + 一行副标题，微软雅黑粗体，字号按画宽比例缩放；
- 底部 7.5% 高深绿色带，写「垃圾分类 · 文明生活」与「公益宣传」，同时盖掉 AI 图右下角的水印。

生成脚本为同目录的 `make_psa.py`，源底图在 `_src/`（`src_img0.png`~`src_img3.png`，均为 1536×1024）：

```
_src/*.png  →  ImageOps.fit 居中裁切到目标比例  →  叠蒙版与文字  →  IMG0~3.BMP
```

改文案只需改脚本里的 `ITEMS` 列表，不重新生成底图；改主题则替换 `_src/` 里的四张 PNG，保持文件名对应即可。

## 格式约束（由 bmp_read.v 决定）

- 未压缩 **24 bpp** BMP，`biCompression = 0`，`biHeight > 0`（自底向上）
- `bfOffBits = 54`（无调色板），`bfSize` 必须等于实际文件长度
- 宽高均 ≤ 4096；`bmp_read` 用 `bfSize` 作 `file_len`，不读目录项里的文件大小
- 扩展名必须是 **8.3 短名中的大写 `BMP`**，且不能是 LFN 项
- 行宽按 4 字节对齐；本组四张宽度 640/800/1024/1280，`w×3` 恰好都是 4 的倍数，无 padding

PIL 保存 RGB 图像为 BMP 时默认写 24bpp、`biHeight` 正数、`bfOffBits=54`，正好满足要求。脚本保存后会重新读回校验尺寸与字节数。

## 读卡预算

停留窗 3 s，三缓冲预读。最大一张 0.89 s，窗内余量 2.11 s。

读卡耗时与源图像素数成正比，与宽高比无关：640×480 最小、1280×720 最大。
四档跨度 3 倍，正好用来验证三缓冲的预读能力——读卡全程落在上一张的停留窗内，
切换延迟不随素材变大而增加。
